# Archivos de ejemplo

## Válidos

- `validos/ejemplo_importacion_valido.txt`
- `validos/ejemplo_importacion_valido.xlsx`
- `validos/operaciones_sucursal_norte.txt`
- `validos/operaciones_sucursal_norte.xlsx`

## Inválidos

- `importe_precision_invalida.*`: importe con más de 2 decimales.
- `encabezados_invalidos.*`: encabezado no reconocido.
- `fechas_mixtas.*`: operaciones con fechas distintas.
- `sin_registros.*`: archivo sin operaciones.
- `fecha_invalida.txt`: fecha fuera de `yyyy-MM-dd`.
- `archivo_vacio.txt`: archivo sin contenido.
