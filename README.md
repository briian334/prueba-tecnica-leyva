# Prueba Técnica Full Stack Java

Aplicación Full Stack para importación de operaciones contables desde archivos TXT y XLSX, generación de pólizas y consulta de sus movimientos.

## Stack previsto

### Backend

* Java 21
* Spring Boot
* Spring Data JPA
* MySQL
* Flyway
* Apache POI
* Maven

### Frontend

* Vue 3
* JavaScript
* Vue Router
* Bootstrap 5
* Vite
